# 02 — Home Feed

> The single, chronological, hyperlocal feed where everything visible to the user appears.

---

## 1. Goal

Make Lokul's feed the **first app they open every morning**: relevant within 50m of home, fast, easy to post into, hard to spam.

---

## 2. User stories

- **US-2.1** As a resident, I open the app and see what's happened in my society and neighborhood in the last 24 hours.
- **US-2.2** As a resident, I can post text + up to 6 photos / 1 video in one tap.
- **US-2.3** As a resident, I can react with one tap (👍 ❤️ 🙏 🤝 ⚠️) and comment.
- **US-2.4** As a resident, I can filter the feed by tag (Safety, Market, Lost, Event, RWA).
- **US-2.5** As a poster, I see who saw/reacted to my post.
- **US-2.6** As an RWA admin, my notice post is **pinned** at top for 24h.
- **US-2.7** As a resident, I can save a post and find it later in "Saved".
- **US-2.8** As a resident, I can report a post; it's hidden for me immediately.
- **US-2.9** As a resident in a quiet society, I see neighborhood posts (≤ 2km) as filler.
- **US-2.10** As a resident, I can mute a specific user or topic without unfollowing.

---

## 3. UX flows

### 3.1 Feed view

```
On open:
- Last-cached feed renders instantly (offline-first)
- "New posts (n)" pill appears at top when new content arrives via Ably
- Pull-to-refresh re-fetches
- Infinite scroll loads older posts in pages of 20
```

**Sections** (in order):
1. **Pinned** (RWA notices, SOS live incidents) — max 3
2. **AI Digest card** ("3 things you missed") — see [12-notifications-digest.md](./12-notifications-digest.md)
3. **Chronological posts** — society first, then tower-floor proximity, then neighborhood ≤ 2km

### 3.2 Post composer

```
+ tap → Composer modal slides up
- Type picker (Update · Safety · Lost · Event · Poll · Sell)
- Text area (multi-line, hashtag autocomplete)
- Media picker (camera / gallery)
- Visibility picker (Society · Tower · Neighborhood)
- Tag chips (auto-suggested from text via on-device model)
- Post button
```

### 3.3 Reactions & comments

```
- Tap heart icon → reaction picker bar (5 emojis)
- Tap comment icon → inline thread (1-level nesting only at v1)
- Long-press a comment → reply, copy, report
```

### 3.4 Pinned & priority

- RWA notices: pinned 24h, configurable per post (up to 7 days).
- Live SOS: pinned until resolved.
- Lost child / pet (high severity): pinned 6h.

## 4. Functional requirements

### Feed composition
- **FR-2.1** Feed MUST return posts ordered by a relevance score:
  ```
  score = recency_decay(0.6) + proximity_boost(0.25) + interaction_boost(0.15)
  ```
- **FR-2.2** Recency decay: exponential, half-life 6 hours.
- **FR-2.3** Proximity boost tiers: same tower (+30), same society (+20), ≤500m (+10), ≤2km (+5), else 0.
- **FR-2.4** A post MUST never appear outside its visibility scope.
- **FR-2.5** Pinned posts MUST always appear above non-pinned, regardless of score.
- **FR-2.6** Feed MUST return ≤ 20 items per page; cursor-based pagination.
- **FR-2.7** New posts MUST arrive via Ably channel `feed:user:{user_id}` and show a "n new posts" pill (not auto-inject).

### Posting
- **FR-2.8** Only Silver+ users can post (Bronze can read only).
- **FR-2.9** Post text limit: 2,000 characters; warning at 1,800.
- **FR-2.10** Media: up to **6 images** (max 5MB each, compressed to 1600px max on client) OR **1 video** (≤60s, ≤80MB).
- **FR-2.11** Video transcoded to HLS by Cloudflare Stream; image variants generated by Cloudflare Images.
- **FR-2.12** Hashtags auto-extracted from text and stored.
- **FR-2.13** Visibility default = "Society"; user can change per post.
- **FR-2.14** Posts of type `safety` must be auto-shared to `neighborhood` scope (visibility lock).
- **FR-2.15** A user can post ≤ 10 posts/day (anti-spam).
- **FR-2.16** A user can edit their post within 15 minutes; after that, only delete.
- **FR-2.17** Soft delete: post hidden but retained 30 days for moderation review.

### Reactions
- **FR-2.18** Reactions: 👍 ❤️ 🙏 🤝 ⚠️ — one per user per post; tap again to remove; switch reaction is allowed.
- **FR-2.19** Reactions update in real-time via Ably.
- **FR-2.20** Reactor list visible to post author only.

### Comments
- **FR-2.21** Comments are 1-level nested only (a reply to a reply still attaches to the original comment).
- **FR-2.22** Comment text limit: 500 characters.
- **FR-2.23** Inline media in comments NOT supported at v1 (link only).
- **FR-2.24** Author can pin one comment per post.
- **FR-2.25** Author can disable comments per post.
- **FR-2.26** Mentions (`@username`) trigger a notification.

### Save / share / report
- **FR-2.27** Save: stored under "You → Saved"; unlimited.
- **FR-2.28** Share: native share sheet; sharing outside Lokul creates a short link (`lokul.in/p/{id}`).
- **FR-2.29** Report: 5 reasons (Spam · Misinfo · Harassment · Off-topic · Other). Reported posts auto-hidden from reporter; queued for moderation (see [14-moderation-admin.md](./14-moderation-admin.md)).

### Mute / hide
- **FR-2.30** Mute user: hide all their posts (and their comments) from feed; reversible.
- **FR-2.31** Mute tag: hide posts with a specific tag from feed.

## 5. Data model

```
posts
  id (ULID)
  author_id (FK users)
  type ('update'|'safety'|'lost'|'event'|'poll'|'sell'|'rwa_notice'|'sos')
  body (text)
  visibility ('tower'|'society'|'neighborhood')
  society_id, tower_id, pin_code, lat, lng
  pinned_until (timestamp nullable)
  comments_locked (bool)
  status ('active'|'hidden'|'deleted')
  created_at, updated_at, deleted_at
  -- denormalised counters:
  reaction_count, comment_count, view_count

post_media
  id, post_id (FK), kind ('image'|'video')
  storage_key, width, height, duration_ms
  order_index

post_tags
  post_id (FK), tag (text)
  -- composite key

reactions
  post_id, user_id, kind ('like'|'love'|'thanks'|'support'|'concern')
  created_at

comments
  id, post_id (FK), parent_id (FK comments nullable for 1-level nesting)
  author_id, body
  created_at, deleted_at

post_views
  post_id, user_id, viewed_at
  -- unique (post_id, user_id)

saved_posts
  user_id, post_id, created_at

mutes
  user_id, target_kind ('user'|'tag'), target_value
```

**Indexes:**
- `posts (society_id, created_at DESC) WHERE status='active'`
- `posts (pin_code, created_at DESC) WHERE status='active'`
- `comments (post_id, created_at)`
- `reactions (post_id)`

## 6. APIs

```
GET    /v1/feed?cursor=...&filter=safety,event
       → { items: [Post...], next_cursor }

POST   /v1/posts
       { type, body, media[], visibility, tags[] }
       → Post

GET    /v1/posts/:id
PATCH  /v1/posts/:id    (within 15 min)
DELETE /v1/posts/:id

POST   /v1/posts/:id/reactions   { kind }
DELETE /v1/posts/:id/reactions

GET    /v1/posts/:id/comments?cursor
POST   /v1/posts/:id/comments    { body, parent_id? }
DELETE /v1/comments/:id

POST   /v1/posts/:id/save
DELETE /v1/posts/:id/save

POST   /v1/posts/:id/report      { reason, note? }

POST   /v1/posts/:id/view        (fire-and-forget; debounced client-side)

POST   /v1/mutes                 { target_kind, target_value }
DELETE /v1/mutes/:id

GET    /v1/me/saved
```

**Realtime channels (Ably):**
- `feed:user:{user_id}` — new posts that pass the user's filter
- `post:{post_id}` — live reaction + comment updates when post is open

## 7. Edge cases

- **EC-2.1** User scrolls fast → only posts that stay in viewport ≥ 500ms count as a view.
- **EC-2.2** Author deletes a post with active comments → comments preserved but inaccessible; counters not shown.
- **EC-2.3** Media upload fails mid-post → post saved as draft locally; retried automatically.
- **EC-2.4** Bronze user tries to post → blocked with a "Verify to post" CTA.
- **EC-2.5** Reaction count drifts due to deletes → recomputed nightly via cron.
- **EC-2.6** Same post receives 1000+ reactions → store full list paginated; UI shows "Top 50 + count".
- **EC-2.7** Society admin pins 4th notice → oldest pinned auto-unpinned.
- **EC-2.8** User reports their own post — disallowed at API layer.
- **EC-2.9** A muted user mentions me → mention notification still fires (mute is for feed, not mentions).
- **EC-2.10** User changes society → old society posts disappear from feed immediately; saved posts retain.

## 10. Out of scope (v1.0)

- Algorithmic "For You" feed (chronological only).
- Cross-post / re-post.
- 2+ levels of comment nesting.
- Reactions on comments.
- Inline media in comments.
- Stories from within feed (Stories live in module 08).
- Hashtag landing pages (search lands users in Meilisearch results instead).
- Boosted/promoted posts (no ads at v1).
